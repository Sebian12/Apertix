# Apertix

**Apertix** is the official website and home of the **Snap** application ecosystem.

The project serves as a central hub where you can:

* 📦 Download desktop applications
* 🌐 Access web versions of supported apps
* 📱 Find mobile releases
* 📖 Learn about each project
* 🚀 Follow development progress

## Apertix ecosystem

| App | Platform | Language |
|-----|----------|----------|
| [SnapPress](https://github.com/Sebian12/SnapPress) | Windows / Linux / Web | Python / JavaScript |
| [SnapPress Android](https://github.com/Sebian12/SnapPress-Android) | Android | Kotlin |
| SnapRename | Windows | C# |
| SnapRename Android | Android | Kotlin |

## Technologies

The website is built using:

* HTML5
* Tailwind CSS
* JavaScript

Hosted with **GitHub Pages**.
